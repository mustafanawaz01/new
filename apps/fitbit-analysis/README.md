# Fitbit Analysis

A personal analytics app that pulls data from the [Fitbit Web API](https://dev.fitbit.com/build/reference/web-api/) and presents it in richer, more granular views than the official Fitbit experience—hourly and minute-level trends, cross-metric comparisons, and exportable insights.
